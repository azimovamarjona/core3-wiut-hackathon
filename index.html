Financial Signal Monitoring

WIUT Hackathon 2026 — Exploratory Data Analysis and Machine Learning approach for predicting escalation probability of financial monitoring signals.

Project Overview

The objective of this project is to estimate the probability that a financial monitoring signal will be escalated.

The target variable is eskalatsiya: 1 represents an escalated signal, while 0 represents a dismissed signal.

Feature Engineering

  • Transaction count
  • Average, minimum and maximum amount index
  • Standard deviation of amount index
  • Incoming and outgoing transaction ratios
  • Transaction type ratios
  • Night-time transaction ratio
  • Number of unique transaction days
  • Weekend transaction ratio
  • 25th percentile of amount index
  • Amount range
  • Hourly and calendar features

Machine Learning Approach

A LightGBM classifier was used to estimate escalation probabilities. The main evaluation metric was ROC-AUC.

Conclusion

The exploratory analysis identified variation across time, transaction characteristics and behavioral features.

Transaction-level aggregation provides a richer representation of each financial signal.

The final model produces an escalation probability for every test signal.
